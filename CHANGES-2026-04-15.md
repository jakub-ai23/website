## Fix: Disabled slide fade-in animations

**Problem:** Content on jakubpopluhar.com was disappearing / not visible on load.

**Root cause:** `.slide-content` had `opacity: 0` by default, only becoming visible once JS added an `.active` class via IntersectionObserver/snap-scroll logic. When the active-class trigger didn't fire reliably (or fired late), slides rendered blank. The hero slide had an override making it visible on load, but slides 2–6 stayed hidden.

**Fix:** Removed the hide-until-active pattern. All slide content now renders at `opacity: 1`, `transform: none`, `transition: none` from first paint. No JS dependency for visibility.

**File:** `index.html` (lines ~1579–1597)

**Commit:** `43fe5ab` — "fix: disable slide fade animations — content always visible"

**Deployed:** GitHub Pages, live on jakubpopluhar.com within ~1 min of push.

**Why kept simple:** Commander's directive — "Turn off all disappearing. Make sure people could see the content straight away." Animations are a tax the site couldn't afford to pay when the trigger was unreliable. Visibility > polish.
